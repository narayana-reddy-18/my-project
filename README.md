# AI-Powered Analytics Dashboard

An AI-powered analytics dashboard built with React and Recharts, featuring interactive data visualization, user-friendly design, and clean, well-documented code.  
Developed as part of a project task to demonstrate modern frontend development skills and deployment best practices.  
Includes live demo deployment and thorough documentation.

## Features

- Interactive charts and graphs using Recharts
- Responsive and clean UI design
- Data filtering and dynamic updates
- Well-structured and commented codebase

## Technologies Used

- Next.js (React framework)
- Recharts (for charts and data visualization)
- JavaScript (ES6+)
- CSS / Styling libraries (if applicable)
