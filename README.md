# AI-Powered Analytics Dashboard

An AI-powered analytics dashboard built with **Next.js**, **React**, and **Recharts**, featuring interactive data visualizations, dark mode, and a clean UI.

[Live Demo](https://my-project-8gk9.vercel.app)

## Features
- Interactive charts (Line, Bar, and Pie) using **Recharts**
- Dark/Light mode toggle
- Responsive and clean layout
- Easy to customize and extend
